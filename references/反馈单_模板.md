## 一、本轮处理的问题

### 1. 参考文献编号根除冲突 ✅

**问题**: numId 自动编号持续破坏章节编号（numId=1冲突→numId=2仍冲突）

**根因**: Word 编号系统是全局扁平的——任何 numId 注入都可能干扰样式链

**R40 修复**: **完全放弃自动编号**，改用手动 `[N]` 前缀拼接文本
```python
make_paragraph('17', f'[{idx}] {ref_text}', font_size=24)
```
移除 abstractNum 2 注入，仅保留章节 heading 编号（numId=100）

**验证**: numId=2: 0 ✅ | 手动 [1] 前缀: True ✅

- `\begin{...}` / `\end{...}` → 移除
- `\item` → 移除
- `\label{...}` → 移除

**验证**: `enumerate/item remnants: False` ✅
